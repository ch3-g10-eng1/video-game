<h1>Notes for editing sprites</h1>

Contains source image files for bob icons & the piskel file for editing  
Add new icons into this folder & pack icons into the Atlas folder using [GDXTexturePacker](https://github.com/crashinvaders/gdx-texture-packer-gui/releases).

[Edit icons using piskel](https://www.piskelapp.com/p/create/sprite/) & load sprites.piskel to edit existing sprites
